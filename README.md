# ClinDent — Clinical Dental Education Management System

A Vite + React + TypeScript application for clinical dental education management.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Deploy to Vercel

Import this repository into Vercel. The included `vercel.json` configures Vite to build with `npm run build` and serve the `dist` directory.

> Keep real API keys and secrets out of Git. Use Vercel Environment Variables for production secrets.
